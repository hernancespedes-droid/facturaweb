# 0.29.0 — Sitio master: suscripciones, módulos y versiones para clientes

## Qué incluye
- **oys.orgysis.site es el sitio master** de O&S (Sistema → Instalaciones de clientes).
- **Cliente del master**: cada instalación nueva se crea también como cliente de OYS (para facturarle); botones «Cliente N» y «Facturarle».
  Las instalaciones anteriores tienen «Crear como cliente del master» en Administrar.
- **Suscripción por cliente** (Administrar): Activa → Aviso de pago pendiente → Sin emitir → Bloqueada, con fechas para que avance sola y mensaje propio.
- **Baja**: «Descargar copia» (.sql.gz con toda la base) y «Dar de baja» (escribiendo la dirección): borra tablas y carpeta; queda un registro sin datos.
- **Módulos por cliente**: cuenta corriente, stock, caja, listados, kiosco, cambios, Mercado Pago, agente VFP, portal. El master tiene todo siempre.
- **Dos carpetas**: el master con `main`, los clientes con `estable`; «Pasar a clientes» mueve `estable` al commit que corre el master. Ver `docs/alta-de-cliente.md`.

## Qué probar (Master en oys.orgysis.site)
1. GIT → actualizar `facturador_web`; Sistema → Aplicar cambios (no hay cambios de base).
2. Armar la carpeta de clientes (doc). Crear un cliente de prueba, cambiarle la suscripción a «Aviso» y entrar a su sitio: ver el cartel.
3. Apagarle un módulo y ver que desaparece del menú. Probar «Sin emitir» (no deja facturar) y «Bloqueada» (no entra el Administrador).

## Revertir
GIT a 0.28.0. Las configuraciones nuevas (suscripción, módulos) se ignoran en 0.28.0: un cliente suspendido quedaría activo.
