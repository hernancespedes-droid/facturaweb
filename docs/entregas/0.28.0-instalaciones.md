# 0.28.0 — Instalaciones de clientes desde la web

## Qué incluye
- **Sistema → Instalaciones de clientes** (solo el Master y solo en la instalación principal): alta de un cliente nuevo con un formulario
  (empresa, CUIT, IVA, subdominio, base vacía, usuario Master, Administrador del cliente con clave provisoria, mail opcional, licencia).
- **Un solo código para todos**: el subdominio del cliente apunta a la misma carpeta `public/`; `config/config.php` elige la configuración por la dirección.
  Cada cliente: su base y su carpeta `storage/instancias/<dirección>/` (config, logs, sesiones, licencia). Nada de `local.php` (base, mail, ARCA, Mercado Pago) pasa a un cliente.
- **Aplicar cambios en todas**: después de actualizar con GIT, aplica los cambios de base en la principal y en cada cliente.
- **Mail, ARCA y licencia** de cada cliente se cambian desde el panel (sin FTP ni SSH).
- Seguridad: una vez creado un cliente, la principal solo responde en sus direcciones (lista editable en el panel); un subdominio sin instalación muestra «no habilitada».
  Nunca se usa una base con tablas ni la base de la principal.

## Qué probar (Master de OYS en oys.orgysis.site)
1. Actualizar con GIT y Sistema → Aplicar cambios (esta versión no trae cambios de base).
2. Panel del hosting: base vacía nueva. Sistema → Instalaciones de clientes → + Nuevo cliente.
3. Panel del hosting: subdominio → misma carpeta `…/public`, SSL. Entrar con el Master y con el Administrador (pide cambiar la clave).
4. Verificar que OYS sigue entrando normal por oys.orgysis.site.

## Revertir
Volver a la versión anterior con GIT. Los clientes creados quedan en `storage/instancias/` (no se borran); sin esta versión, sus subdominios mostrarían la principal:
borrar o renombrar esos subdominios en el panel antes de revertir.
